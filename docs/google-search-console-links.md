## Prioridade pra solicitar indexação manual

O Search Console limita ~10 solicitações manuais por dia. Comece pelas de maior prioridade:

1. `/` (home)
2. `/atuacao`
3. `/avaliacao`
4. `/empresas`
5. `/blog`
6. Páginas de condição mais buscadas: `/ansiedade`, `/depressao`, `/tdah`
7. Hubs do blog (`/blog/tema/...`)
8. Posts do blog (em ordem de relevância clínica/SEO)

## Atualização

Quando adicionar/remover páginas, atualize:
1. `public/sitemap.xml`
2. Esta lista (`docs/google-search-console-links.md`)
3. Reenvie o sitemap no Search Console (ou aguarde o re-crawl).
