# Psiquiatra João Pedro Castro

## Project Overview
This project aims to provide a comprehensive resource for individuals seeking psychiatric assistance. The application offers features such as appointment scheduling, medication management, and an extensive library of mental health resources.

## Features
- **User Authentication**: Secure login for users to access their personal data.
- **Appointment Scheduling**: Users can book, modify, and cancel appointments.
- **Medication Tracker**: Users can manage their prescriptions and receive reminders.
- **Resource Library**: A collection of articles, videos, and tools related to mental health.

## Getting Started
To run this project locally:
1. Clone the repository:
   ```
   git clone https://github.com/JoaoCastroF1/psiquiatrajoaopedrocastro.git
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Run the application:
   ```
   npm start
   ```
